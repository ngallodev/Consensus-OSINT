## Scope and discovery limits

The exact-worktree full graph indexed 4,593 nodes / 14,913 edges at generation `2026-11-06T00:00:28Z`; it excluded `consensus_osint/vendor/`, 34 assets, and two Jinja templates had unusable parses. Graph coverage is best effort. Direct source searches for HTTPX, requests, urllib, aiohttp, curl_cffi, DNS, sockets, subprocesses, browsers and updates covered core/adapters/vendor, but the large provider tree was not traced provider by provider. A representative vendor search found multiple independent client families; it is not a complete reachability proof. Static template inspection found no `fetch`/XHR in the two templates; rendered/browser behavior was not tested.

For controlled results, exact commands, environment and limitations see [Phase 1 report](phase-1-report.md). Strict mode is not an OS firewall, does not authenticate a route as proxyctl-selected or guarantee scan exit failure when the proxy fails, and is not approved for live collection. External egress enforcement and per-path acceptance remain required.
